# Application Funnel Insights

*Developed by Ritu Raj Singh*

## Project Overview

This project analyzes the application funnel to understand application volume, shortlisting, interviews, selections, rejection patterns, company activity, skills, regions, and processing time.

The objective is to convert application data into clear and decision-oriented business insights through data cleaning, analysis, and visualization.

## Project Workflow

*Raw Data → Excel Cleaning → Python Analysis → Tableau Dashboard → Business Insights*

## Data Cleaning

The raw application dataset was cleaned in *Microsoft Excel*.

The cleaning process included:

* Removing duplicate records
* Handling missing values
* Standardizing text formats
* Correcting inconsistent categorical values
* Checking invalid numeric values
* Standardizing date formats
* Validating the final dataset

The cleaned dataset was then used for analysis and visualization.

## Analysis

Python was used for analytical calculations and summary analysis, including:

* Application status analysis
* Application funnel metrics
* Company-wise analysis
* Skill-wise analysis
* Education analysis
* Region analysis
* Gender analysis
* Experience analysis
* Monthly application trends
* Processing time analysis
* Business insights

## Tableau Dashboard

The interactive Tableau dashboard provides:

* Application status overview
* Monthly application trend
* Company performance
* Skill analysis
* Region analysis
* Processing time analysis
* Key application funnel KPIs

## Tools Used

* Microsoft Excel
* Python
* Pandas
* NumPy
* Tableau
* GitHub

## Key Outcome

The project provides a clear view of the application funnel and helps identify application patterns, company activity, candidate skills, regional trends, and processing performance for better decision-making.
